# Gnomon 静帧成像服务

Python CPU 三角网格成像后端。输入 JSON 网格、PNG 纹理和有层级的场景，输出颜色、深度、世界法线、对象标识、覆盖率及采样世界坐标。用途是三维静态插图与材质校样，不需要 GPU 或外部服务。

## 启动

需要 Python 3.11+。本批实际使用 Python 3.14 / macOS arm64。

```sh
python3 -m venv .venv
.venv/bin/pip install -e '.[examples]'
.venv/bin/python -m compileall -q gnomon
.venv/bin/python -m gnomon.demo --output run-output
GNOMON_DATA=.gnomon-data .venv/bin/uvicorn gnomon.api:app --host 127.0.0.1 --port 8737 --workers 1
```

打开 http://127.0.0.1:8737/docs 浏览 OpenAPI。服务仅设计为单进程；CPU 成像请求同步返回，完成/失败状态持久化。目录由服务独占，重启将中断的未完成记录标记 failed；重新提交可生成新结果。

服务运行后可执行 `.venv/bin/python examples/http_walkthrough.py`，通过真实 HTTP 上传样例并下载静帧。

## 成像约定

- 右手世界坐标；Y 向上，相机看向 target。旋转单位为度，局部顺序为 X、Y、Z，随后由父节点变换进入世界空间。
- 透视 fov 为垂直视角，正交 span 为垂直世界长度；near/far 为正距离。六个齐次平面裁剪后进行透视校正插值。
- PNG 纹理按未附 ICC 的 sRGB 解码，UV 原点在左下，双线性采样。repeat/clamp 均可。alpha_cutoff 是二值裁切，不表示半透明混合。
- 材质基色为 sRGB，着色和抗锯齿平均在线性空间，PNG 最后编码回 sRGB；超出显示范围的亮度仅在 PNG 截断，NPZ 保留。
- 环境遮蔽（occlusion）是可选的屏幕空间接触变暗：渲染请求带 `occlusion` 对象才启用，只缩放环境光项，定向光、unlit 表面和背景不受影响；通道值 1 为开阔、0 为完全遮蔽，未启用时全 1。详见下文「环境遮蔽」。
- 生成法线为相邻三角形面积加权；可显式提供逐顶点法线。非均匀缩放使用逆转置法线变换。
- 单面剔除按变换后的顶点绕序；镜像会翻转绕序。双面不会自动把法线朝向相机。共面等深片元保留场景遍历时先出现的表面。
- samples=1/2/3 是每轴均匀采样。颜色是全体子采样含背景的平均；拾取、深度、法线、世界位置来自最近的有覆盖子采样。对象标识为场景节点序号，0 为背景。
- region=[x,y,w,h] 使用整图左上坐标和原始镜头，不改变构图。输出像素坐标是区域内坐标；拾取另返回全图子采样位置。
- 深度 NPZ 是 OpenGL NDC [-1,1]，背景为 +inf；depth.png 每张按自身有效深度范围做可读预览，不能当作物理距离或跨图绝对标尺。

## 环境遮蔽

没有投影阴影时，凹槽、接缝和相互贴近的部件容易显得平。环境遮蔽（AO）在成像后估计每个像素朝向天空的半球被附近几何挡住的比例，让接触面附近变暗，从而恢复这些部位的空间层次。它是屏幕空间方法：只依赖已光栅化的最近深度层，不投射阴影、不改变轮廓。

### 启用与显色

渲染请求带可选的 `occlusion` 对象才启用，未启用时行为与之前完全一致（occlusion 通道全 1）：

```json
{"scene": "scene_…", "width": 512, "height": 512,
 "occlusion": {"radius": 0.3, "samples": 24, "strength": 1.0, "bias": null}}
```

遮蔽只缩放光照的**环境光项**（`light.ambient`）：`颜色 = 基色 × (ambient × 可见度 + energy × 余弦)`。定向光、unlit 表面和背景不变暗，因此它表达的是"环境光被挡住"，而不是多了一盏灯或一层投影。`occlusion.png` 是可见度灰度图（白=开阔），`channels.npz` 的 `occlusion` 保存 [0,1] 浮点值，像素拾取也会返回该值。

### 判定规则

每个覆盖像素沿法线（双面片元取朝向镜头一侧）发出半球采样核，采样点经渲染相机投影回画面，读取该处最近表面：若它比采样点更靠近镜头则计为一次遮挡，并按采样点与遮挡面的**世界空间距离**加权——距离超过 `radius` 权重为零。因此两个只是在投影里重叠、实际相距很远的表面不会被当成接触；只有真正进入细节半径的几何才会压暗对方。遮挡判定使用视线深度，与投影方式无关，正交和透视镜头结果一致。

### 半径、噪声与开销

- `radius`（世界单位，必填）：细节半径，决定变暗的空间范围。取要表现的凹槽/接缝尺度（如 0.5–2 倍槽深）；过大会把接触渐变拖得很长、对比变弱，并增大区域渲染的外扩边距（见下），过小则只剩轮廓线。半径本身不改变采样数。
- `samples`（4–64，默认 16）：每像素半球采样数。开销与 `samples × 像素数` 成正比，与半径无关。每个像素的核按整图坐标哈希旋转，样本不足时大片平面上呈颗粒噪声而非条带；16 适合草稿，24–32 适合成稿，平滑表面特写可到 64。噪声图案确定且对齐整图：同一像素在任何区域渲染、任何重复提交中取值相同。
- `strength`（0–1，默认 1）：遮蔽强度，插画时常用 0.6–0.8 避免死黑。
- `bias`（默认 0.025×radius）：采样起点沿法线的偏移，防止平面自我遮蔽；表面近乎共面出现脏斑时适当加大。

### 区域渲染与预算

AO 需要读取请求区域之外至多一个半径的邻域。启用后服务按半径和镜头保守外扩实际渲染区域（透视按 near 平面估计，半径 ≥ near 时退化为整帧），计算完再裁回请求区域，因此**区域渲染结果与整图裁切逐像素一致**。缓冲预算按外扩后的区域估算，`/v1/preflight` 的 `effective_region` 和 `estimated_buffer_bytes` 会显示实际开销；透视镜头下近裁剪面很近、半径较大时边距可能很大，应缩小区域或半径。

### 适用边界

- **凹角**是最佳场景：内角、槽底、接缝处半球被两侧壁挡住，变暗最强且随半径自然衰减；凸角不会被错误描边。
- **薄片**：深度缓冲只存最近一层。零厚度薄片能压暗它下方的地面（间隙在半径内时），但薄片自身的受光面不会收到来自其下方物体的遮蔽——这在几何上也是正确的。单面剔除的薄片从背面不可见，也就不会从背面向外投射遮蔽；`alpha_cutoff` 镂空处不占深度，镂空孔洞会正常"透光"。
- **画面外与被遮挡的邻近物体不参与遮蔽**：估计只看得见已渲染的最近深度层。贴近画面边缘的接触可能缺少来自画外物体的变暗；被前景完全挡住的几何也不会在后方表面留下遮蔽。需要完整接触关系时，把相关物体纳入画面（或拉远镜头）再渲染。
- AO 是视角相关的屏幕空间近似，不是物理阴影：它不依赖光源方向，也不能替代投射阴影表达"光被挡住"的方向性。

## 工作流

| 入口 | 结果与边界 |
|---|---|
| POST /v1/meshes | 三角索引、面积、法线、UV、包围盒校验，退化面拒绝 |
| POST /v1/textures | PNG 解码、直通透明度、尺寸与格式约束 |
| POST /v1/scenes | 唯一键、父图、资源和相机校验，不可变场景 |
| POST /v1/scenes/{id}/revisions | 完整新修订，predecessor 追溯，不覆盖前版本 |
| POST /v1/preflight | 世界包围盒、可见三角数、预计帧缓冲与可受理判断 |
| POST /v1/renders | 冻结场景和实际资源，生成六张 PNG、channels.npz、metadata.json |
| GET /v1/renders/{id}/pixels/{x}/{y} | 最近子采样表面及其世界坐标，背景返回空表面 |
| POST /v1/comparisons | 相同镜头、尺寸、区域与采样规则下，比较线性颜色、轮廓、语义节点及深度 |
| POST /v1/sheets | 绕目标的多个 Y 轴视角，整合 sheet.png 与 index.json |
| POST /v1/renders/{id}/bundles | 自描述 ZIP，包含资源输入、通道语义及逐文件摘要 |
| POST /v1/resources/{id}/state/retired | 拒绝新场景绑定，旧场景继续引用；active 可恢复 |
| POST /v1/scenes/{id}/state/archived | 阻止新成像；active 可恢复，已有产物可读 |

## 环境和资源边界

每个网格最多 20,000 顶点 / 30,000 三角，场景最多 100 节点 / 60,000 可见三角。纹理最多 1024×1024，编码 PNG 最多 4 MB。成像边长 16–1024，保守估算采样缓冲不超过 160 MiB（启用环境遮蔽时按外扩后的区域估算）；这不是整个 Python 进程的内存限制，解码资源、JSON、数组临时副本和归档还需要内存。静帧没有投影阴影、透射、骨骼、动画或外部模型格式导入；环境遮蔽是屏幕空间的接触变暗，不属于阴影投射。

`.gnomon-data/gnomon.sqlite3` 保存记录，artifacts/ 保存校验摘要的结果。运行产物不进入 Git。应使用同一目录和单个 worker；不承诺跨进程互斥或分布式执行。HTTP 是可信环境中的成像接口，不含身份系统；不要直接暴露到公共网络。
